# Feature Engineering — Kaggle Course Solutions

This repository contains my completed exercises and notes from the [Feature Engineering](https://www.kaggle.com/learn/feature-engineering) course by Kaggle Learn.  

The course focuses on practical techniques to improve model performance by transforming raw data into more informative features. All exercises were completed in Python using the Kaggle environment.

---

## 📘 Course Overview

The **Feature Engineering** course covers key topics essential for enhancing predictive models through data transformation and enrichment.  

### Topics covered:
1. **Baseline Models**
2. **Data Leakage**
3. **Feature Creation**
4. **Categorical Encoding**
5. **Feature Scaling**
6. **Feature Selection**

---

## 💡 What I Learned

- How to identify and prevent **data leakage**.  
- Techniques for **encoding categorical variables** (one-hot, ordinal, target encoding).  
- Using **feature scaling** (standardization and normalization).  
- Creating **new informative features** from existing data.  
- **Feature selection** methods to reduce overfitting and improve generalization.  
- Building **stronger baselines** and evaluating model improvement quantitatively.

---

## 🧠 Tools and Libraries Used

- **Python 3**  
- **Pandas**, **NumPy**  
- **Scikit-learn**  
- **XGBoost**  
- **Matplotlib**, **Seaborn**
